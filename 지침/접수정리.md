# 접수 정리 지침

접수 원문 1건을 읽고 하자대장의 해석 필드를 JSON 하나로 돌려준다.
기준은 `data/업무설명_하자보수.md`. 충돌하면 그 문서가 우선한다.

## 입력
- 접수 원문 1건 (현장 메모, 메일, 메신저 대화 중 하나)
- 원문 파일명 (예: `04_20261105_2F화장실_물고임.txt`)

## 출력
- **JSON 객체 하나만** 출력한다. 설명 문장, 인사, 코드블록(```) 표시를 붙이지 않는다.
- 원문 1건당 객체 1개. 여러 건을 한 번에 묶지 않는다.
- 키는 아래 6개를 이 순서와 이름 그대로 쓴다.

```json
{
  "접수일": "YYYY-MM-DD 또는 null",
  "위치": "층 구역",
  "공종": "방수|타일|전기|설비|기계|도장|바닥재|미정 또는 후보를 /로 연결",
  "하자내용": "40자 이내 요약",
  "긴급도": "긴급|높음|보통",
  "근거": "공종과 긴급도를 정한 원문 단서 한 문장"
}
```

## 필드별 규칙

### 접수일
- 원문에 적힌 날짜를 `YYYY-MM-DD`로 쓴다. 메일은 `날짜:` 줄, 메모·메신저는 첫 줄의 날짜.
- 원문에 날짜가 없으면 `null`. 파일명 날짜로 채우는 일은 코드가 한다. 추측하지 않는다.

### 위치
- `층 구역` 형식. 층은 `B2`, `B1`, `1F`, `2F`처럼 쓴다. (예: `B1 푸드코트`, `2F 화장실`)
- 매장 번호, 기둥 번호, 남녀 구분, 세면대 앞 같은 세부 위치는 위치에 넣지 않고 하자내용에 쓴다.
  - 예: "B2 주차장 C구역 기둥 C-12" → 위치 `B2 주차장`, 하자내용에 `C-12 주변` 포함
- 구역은 원문에 나온 시설·구역 이름을 쓴다. 원문에 없는 구역을 만들지 않는다.

### 공종
아래 단서로 판단한다.

| 공종 | 원문 단서 |
|---|---|
| 방수 | 누수, 천장에서 물 떨어짐 |
| 타일 | 타일 들뜸·깨짐·줄눈, 바닥 기울기 |
| 전기 | 조명, 콘센트, 분전반, 누전, 전원 |
| 설비 | 배관, 배수 막힘, 급수, 수전 |
| 기계 | 자동문, 셔터, 주차 차단기, 엘리베이터, 에스컬레이터 |
| 도장 | 페인트 벗겨짐·변색 |
| 바닥재 | 에폭시, 바닥 코팅, 장판 |

- 원문만으로 하나로 정할 수 없으면 후보를 `설비/타일`처럼 `/`로 이어 쓴다. 현장을 보고 정하는 것은 담당자다. **단정하지 않는다.**
- 어느 단서에도 해당하지 않으면 `미정`.
- 에스컬레이터 "앞" 통로처럼 장비 이름이 위치로만 나온 경우는 장비 공종(기계)으로 보지 않는다. 하자가 난 대상(타일)으로 판단한다.

### 하자내용
- 40자 이내 한 문장. 세부 위치와 증상을 사실대로 쓴다.
- 원문에 없는 원인이나 판단을 넣지 않는다.
- 사진 장수, 임시 조치 같은 부가 정보는 40자를 넘기면 뺀다.

### 긴급도
세 단계 중 하나. 여러 기준에 걸리면 **가장 높은 단계**를 쓴다.

| 긴급도 | 기준 |
|---|---|
| 긴급 | 누수, 전기 이상, 고객 안전 위험(넘어짐·미끄러짐·추락) |
| 높음 | 고객 출입·영업 지장(출입문·자동문·주차 출구 이상, 고객 시설 사용 불가, 고객 민원) |
| 보통 | 그 외(미관, 운영 지장 없음) |

- **고객 = 이용 고객.** 입점 매장(테넌트) 점장·직원의 문의나 일정 질문은 고객 민원이 아니다.
- 고객서비스팀이 전달한 이용 고객 민원은 고객 민원이다.
- 미끄럼 주의 표지판, 안내 콘 같은 임시 조치가 있어도 위험 기준은 그대로 적용한다.

### 근거
- 공종과 긴급도를 정한 단서를 원문 표현으로 한 문장에 쓴다. 사람이 검수할 때 읽는다.
- 공종이 후보로 갈린 경우 왜 갈렸는지 쓴다.

## 하지 않는 일
아래는 코드가 계산하므로 출력에 넣지 않는다.
- 접수번호, 조치기한
- 공사번호, 시공업체, 준공일, 보증만료일, 보증판정, 책임구분, 상태, 비고(`만료임박`)

## 예시

원문: `04_20261105_2F화장실_물고임.txt` (2F 여자화장실 세면대 앞 물 고임, 배수 또는 기울기 불명, 미끄럼 주의 표지판 설치)

```json
{"접수일":"2026-11-05","위치":"2F 화장실","공종":"설비/타일","하자내용":"여자화장실 세면대 앞 바닥 물 고임, 청소 후 재발","긴급도":"긴급","근거":"배수 불량인지 바닥 기울기인지 원문에서 알 수 없어 후보 병기, 미끄러짐 우려로 긴급"}
```

원문: `07_20261109_4F외벽_도장.txt` (4F 입점매장 점장이 외벽 페인트 벗겨짐과 보수 일정 문의, 누수 없음)

```json
{"접수일":"2026-11-09","위치":"4F 외벽","공종":"도장","하자내용":"매장 창 바깥쪽 외벽 페인트 군데군데 벗겨짐","긴급도":"보통","근거":"페인트 벗겨짐은 도장, 입점매장 점장의 문의는 고객 민원이 아니고 누수·안전 위험 없음"}
```
